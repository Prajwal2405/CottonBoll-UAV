# CottonBoll-UAV

A spatially disjoint UAV benchmark for dense cotton boll detection.

This repository holds the code, splits, configs, result tables and baseline weights for the WACV 2027 Harvest-Vision workshop paper:

> **CottonBoll-UAV: Dense Small-Object Detection in UAV Imagery for Automated Cotton Yield Estimation**
> Prajwal Mahesha Sethurani, Prabha Sundaravadivel, Varun Valluvan, Lakshman Tamil, H. Allen Torbert

The imagery and labels are too large for GitHub and are archived separately (see [Data](#data)).

## At a glance

| | |
|---|---|
| Frames | 1,857 nadir frames, 12 m AGL, 3.2 mm/px, two fields (pre- and post-defoliation) |
| Tiles | 148,560 tiles, 640 × 640 px, 100 px overlap (80 per frame) |
| Split | Spatially disjoint: test strips at each end of each field, 13 m exclusion buffers |
| Training labels | 96,080 tiles, generated by an annotator model and filtered by cross-tile agreement |
| Evaluation set | 1,215 hand-verified test tiles, 217,045 boxes (192,679 retained proposals + 24,366 added during human verification) |
| Baselines | YOLOv5n-u, YOLO11n, YOLO11s; F1 0.920–0.929 |

## Repository layout

```
notebooks/
  1_annotation/     annotator ("teacher") model, evaluation-set pre-annotation, training-label generation
  2_baselines/      baseline training (YOLOv5n-u, YOLO11n, YOLO11s)
  3_evaluation/     evaluation on the verified set, operating-point sweep, retained-vs-added analysis
  4_experiments/    random-vs-spatial split (Sec. 5.5), cross-condition transfer (Sec. 5.4), figures
  5_edge_kv260/     ReLU variant used for the AMD Kria KV260 deployment (Sec. 6)
splits/             tile lists for every experiment in the paper
configs/            exact Ultralytics training arguments for each baseline
results/            the result tables behind the paper, plus per-epoch training logs
audit/              provenance records for the annotator seed set and the evaluation-set edits
```

## Getting started

The notebooks were run in Google Colab (NVIDIA L4) with Ultralytics 8.4.x, Python 3.12/3.13 and PyTorch 2.11.

```bash
pip install -r requirements.txt
```

Paths in the notebooks point to the authors' Google Drive (`/content/drive/MyDrive/cotton_bench/...`). Change them to wherever you extracted the data.

Quick evaluation of a baseline on the verified set:

```python
from ultralytics import YOLO
model = YOLO("yolo11s_best.pt")
metrics = model.val(data="eval_set.yaml", imgsz=640, max_det=1000, conf=0.001, iou=0.5)
```
